# Test scope

All 19 required Node SDK checks must pass on Google and Rust. The listener check includes a live update. No required operation is skipped.

The example covers increment, array union, field deletion, and server timestamps.
Firestore maximum/minimum/array-remove transforms, aggregation, partition
queries, Security Rules, and production transaction isolation remain outside
this example. Storage resumable retry recovery and IAM remain outside it. See
the root README for local emulator limits.
